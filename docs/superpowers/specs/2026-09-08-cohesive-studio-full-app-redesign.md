# 全系统视觉与工作流闭环（Cohesive Studio）全面重构设计规范

- **日期**: 2026-09-08
- **状态**: Draft (待用户确认)
- **涵盖页面**: 首页（`HomePage`）、会话与审计（`SessionsPage` / `SessionDetailPanel`）、定时任务（`CronPage`）、设置与工作区（`ConfigHub`）

---

## 1. 目标与设计背景

继「自动化任务工作台（Automations Studio）」重构后，用户提出对其他核心页面的整体体验进行系统化升级。通过走查，目前以下四个核心页面仍存在割裂与低效问题：

1. **首页（HomePage）**：
   - 目前缺少自动化运行状态的透视，任务执行、定时计划与首页完全脱节；
   - 缺少一键触达核心操作的快捷工作流入口。
2. **活动与会话（Activity / Sessions & SessionDetailPanel）**：
   - 会话历史长对话动辄数十甚至上百条交互，缺乏按消息类型（用户指令、模型响应、工具调用、思考过程）的过滤能力，排查和阅读极不方便；
   - 会话列表中 Token 消耗与计费元信息视觉层级不够清晰。
3. **定时调度（CronPage）**：
   - 左侧配置栏固定 `w-80` 与右侧列表在宽屏下比例失衡；
   - 定时计划卡片缺乏对通知策略（`notify_on`）以及人类友好相对倒计时的清晰展示。
4. **设置与工作区（ConfigHub）**：
   - 工作区路径输入框采用朴素的下划线输入，与全站其他卡片风格不统一；
   - 资源分组卡片与资源库（`ResourceHub`）缺乏一键跳转联动。

---

## 2. 页面重构详细规范

### 2.1 首页（HomePage）—— 统一总控仪表盘

1. **自动化监控微件（Automation Status Widget）**：
   - 并行获取 `/api/tasks/runs` 与 `/api/schedules`；
   - 展示当前活跃运行任务数（运行中呼吸点灯）、今日运行总数与成功率；
   - 展示下一个即将触发的定时调度任务名称与时间；
   - 提供直达 `/automations/tasks` 与 `/automations/schedules` 的快捷链接。
2. **Hero 区域三合一快捷工作流**：
   - 「启动 Agent 终端」（前往 `/agent/terminal`）；
   - 「新建任务」（前往 `/automations/tasks`）；
   - 「配置定时计划」（前往 `/automations/schedules`）。
3. **系统指标卡片微调**：
   - 内存、CPU、磁盘使用率增加渐变光泽色与状态指示圆点。

---

### 2.2 会话详情抽屉（SessionDetailPanel）与会话列表（SessionsPage）

1. **会话详情长消息类型过滤器（Message Filter Bar）**：
   - 在详情抽屉顶部添加紧凑过滤选项：
     - `全部 (All)`
     - `用户指令 (User)`
     - `模型回复 (Assistant)`
     - `工具调用 (Tools)`
     - `思考过程 (Thinking)`
   - 点击过滤仅渲染符合该类型的消息气泡，大幅提升长上下文审计回溯效率。
2. **会话列表项元数据强化**：
   - 费用（Cost）使用独立徽章强调；
   - Token 数量与模型引擎展示更加清晰分明。

---

### 2.3 定时任务页（CronPage）—— 宽屏网格与触发器透视

1. **响应式自适应栅格（Responsive Grid）**：
   - 替换现有的 `flex flex-col lg:flex-row`，升级为 `grid grid-cols-1 xl:grid-cols-12 gap-6`；
   - 左侧创建/编辑表单占 5 列（`xl:col-span-5`），右侧自然语言解析与定时计划列表占 7 列（`xl:col-span-7`），左右视觉比重大气平衡。
2. **通知策略与时间戳标签**：
   - 定时任务卡片展示 `notify_on` 状态徽标（如 `通知: 总是 / 仅成功 / 仅失败`）；
   - 下次执行时间展示格式化绝对时间 + 相对倒计时（如 `下次: 明天 09:00 (14 小时后)`）。

---

### 2.4 设置与工作区（ConfigHub）—— 规范化控件与分组直达

1. **工作区路径输入框现代化**：
   - 将无边框下划线输入升级为带有文件夹图标的规范输入框；
   - 保持路径缺失时的警告高亮与错误提示。
2. **资源分组卡片一键直达**：
   - 每个资源分组（Group）卡片右侧增加「查看资源（View Resources）」按钮，点击一键导航至 `/settings/resources`，并预选该分组。
3. **未保存更改常驻浮动栏优化**：
   - 浮动栏显示“检测到 X 项未保存更改”，操作按钮提供清晰的保存状态。

---

## 3. 技术约束与规范

1. **零外部依赖**：仅使用现有依赖，禁止新增 npm 包。
2. **双语字典对齐**：所有新增文案同步至 `web/frontend/src/i18n/locales/en.ts` 与 `zh.ts`。
3. **测试覆盖**：所有既有 44 个前端测试文件全部保持 100% 通过，且为新增交互编写对应单元测试。
4. **Python 后端兼容**：不修改既有 API 协议，保证 `uv run pytest`、`uv run ruff check .`、`uv run mypy core` 全程绿灯。
