# TODO 清理

## Objective (目标)
收集代码库中的 TODO、FIXME、HACK 注释，把已经放太久的挑出来。

## Context (背景)
这些标记会无声地堆积，从来没有人把它们当作一个整体来看。区分"备注"和"欠债"的，是时间。

## Instructions (指令)
1. 在被跟踪的源文件中搜索 TODO、FIXME、HACK。
2. 用 `git log -1 --format=%ai -L` 或 `git blame` 找出每一行是什么时候写下的。
3. 按存活时长从长到短排序，并按代码库区域分组。
4. 指出其中看起来已经被解决或已不再适用的条目。不要删除任何东西。

## Verification (验证)
每条记录都有文件、行号，以及取自 git 历史的引入时间。没有文件被修改。
